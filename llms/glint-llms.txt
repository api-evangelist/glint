# Glint (Microsoft Viva Glint)

> Glint is an employee-engagement and organizational-health platform built on people-science pulse surveys, manager dashboards, and action-planning analytics. Founded in 2013 and backed by Bessemer Venture Partners and Shasta Ventures, Glint was acquired by LinkedIn in 2018 and is now shipped by Microsoft as Microsoft Viva Glint within the Microsoft Viva employee-experience suite. There is no standalone public Glint developer API, OpenAPI, or developer portal; the product is administered through the Microsoft 365 tenant and Microsoft Entra ID.

## Notes
- No first-party public REST API, OpenAPI specification, SDK, or CLI is published for Glint.
- Programmatic access to Viva employee-experience data is provided through Microsoft 365 / Microsoft Graph, not a standalone Glint API.
